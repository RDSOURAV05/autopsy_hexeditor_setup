Verification & Testing Guide

HxD Verification

  • Launch HxD from the Start menu.
  • Press Ctrl + O to open any sample file.
  • Verify hexadecimal and ASCII columns render properly.

Autopsy Verification

  • Launch Autopsy from Desktop / Start menu.
  • Click 'Create New Case' on the startup window.
  • Confirm module indexing and Java runtime load cleanly.
